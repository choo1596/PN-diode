## 1. 어떤 그림이 어디에 나오는가

| 슬라이드 내용 | 시뮬레이터에서 보는 법 |
|---|---|
| 소수캐리어 분포와 SCR 경계의 **접선 기울기** | 왼쪽 위 패널. 점선 접선이 평형선과 만나는 점 λ 를 함께 표시 |
| **Long / Intermediate / Short base** 분포 비교 | `Long base` · `Intermediate` · `Short base` 프리셋, 또는 `W`, `L` 슬라이더 |
| p측 short + n측 long **혼합** | `p:short / n:long` 프리셋 |
| **역방향** 에서 경계 농도가 0으로 빠지는 것 | `역방향` 프리셋. `V_a` 를 더 내리면 분포는 그대로고 SCR만 넓어짐 |
| 위치에 따른 **전류밀도** `J_n(x)`, `J_p(x)`, `J_Total` | 왼쪽 아래 패널 (위 패널과 x축이 정렬되어 있음) |
| 중성영역 **재결합 없음** → J_n, J_p 각각 일정 | `Short base` 프리셋. W ≪ L 이면 두 곡선이 저절로 평평해짐 |
| 이상 다이오드 식 `J = J_s(e^{eVa/kT} − 1)` | 오른쪽 패널. `−J_s` 표시, 현재 동작점 마커 |

### 접선이 만나는 점 λ

접선을 평형선까지 늘리면 `λ = L·tanh(W/L)` 에서 만납니다. 그래서

* **Long base** (W ≫ L) → `λ = L`, 기울기 = `n_p0(e^{eVa/kT}−1)/L_n`
* **Short base** (W ≪ L) → `λ = W`, 기울기 = `n_p0(e^{eVa/kT}−1)/W_p`

가 되고, 이것이 슬라이드에 적힌 두 기울기 식입니다. 시뮬레이터는 λ 점을 찍고
어느 극한에 있는지 라벨로 알려줍니다.

## 2. 조작

마우스만으로 전부 됩니다. 슬라이더 핸들 24 px, 좌우 `−`/`+` 로 한 단계씩,
**J–V 그래프 위를 클릭·드래그하면 `V_a`** 가 그 전압으로 갑니다.

| 슬라이더 | 범위 | 무엇이 바뀌나 |
|---|---|---|
| `V_a` | −1.0 … +0.8 V | 경계 농도, 전류, 동작점 (역방향이면 SCR도 넓어짐) |
| `W_p`, `W_n` | 0.1 … 500 µm | long ↔ short base 전환 |
| `L_n`, `L_p` | 0.1 … 500 µm | 같은 전환을 반대쪽에서 |
| `N_a`, `N_d` | 1e14 … 1e19 cm⁻³ | `n_p0`, `p_n0` 와 `J_n` : `J_p` 비중 |

`?embed=1` 제목 숨김 · `?plot=profile` 분포+전류만 · `?plot=iv` J–V만 ·
`?test=1` 자체 검증. 슬라이더 상태는 주소에 저장되므로 `링크 복사` 로 그대로 공유됩니다.

## 3. 모델 (이게 전부입니다)

300 K 고정, `n_i = 1.5×10¹⁰ cm⁻³`, `D_n = 25`, `D_p = 10 cm²/s` 고정.

```
n_p0 = n_i²/N_a                p_n0 = n_i²/N_d
n_p(0) = n_p0 · e^{eVa/kT}     p_n(0) = p_n0 · e^{eVa/kT}      (저준위 주입)

δn_p(x″) = δn_p(0) · sinh((W_p − x″)/L_n) / sinh(W_p/L_n)
J_n(x″)  = e·D_n·δn_p(0)/L_n · cosh((W_p − x″)/L_n) / sinh(W_p/L_n)

J_n(−x_p) = e·D_n·δn_p(0)/L_n · coth(W_p/L_n)      (n측도 같은 꼴)
J_Total   = J_n(−x_p) + J_p(x_n)  =  J_s·(e^{eVa/kT} − 1)
```

`sinh` 일반해 하나가 long / intermediate / short base 를 모두 덮습니다
(`W/L ≫ 1` 이면 지수 감쇠, `W/L ≪ 1` 이면 직선). 구현은 모든 지수 인자가 0 이하가
되도록 정리해서 `W/L` 이 아무리 커도 오버플로우가 없습니다.

`V_bi`, 공핍층 폭 `W = sqrt(2ε(V_bi−V_a)/q · (1/N_a + 1/N_d))` 는 SCR 을 그리는 데만
씁니다.

## 4. 유효 범위 · 그림에 관한 정직한 이야기

* **저준위 주입만** 다룹니다. `δ(0)/N > 0.1` 이 되면 상단에 한 줄로 알려주니
  `V_a` 를 낮추거나 도핑을 올리세요. 고준위 주입은 이 시뮬레이터의 범위 밖입니다.
* 분포 패널의 **y축은 좌우가 따로**입니다. 슬라이드 그림도 SCR 양쪽에 "n, p" 화살표
  축을 하나씩 그립니다. 도핑이 비대칭이면 `n_p0` 와 `p_n0` 가 10배 이상 차이 나므로
  공유 축으로는 한쪽이 보이지 않습니다.
* `p_p0`, `n_n0` 는 소수캐리어보다 여러 자릿수 위라 선형 축에 들어오지 않습니다.
  슬라이드와 같이 위쪽에 **축척 밖 참조선**으로 그리고 그렇게 표기했습니다.
* **SCR 폭은 과장해서** 그립니다. 실제 폭은 0.1~0.3 µm 로 W 대비 1/1000 수준이라
  그대로 그리면 보이지 않습니다. 단, `sqrt(V_bi − V_a)` 에 따라 넓어지고 좁아지는
  거동은 살아 있어서 역방향에서 넓어지는 것을 볼 수 있습니다.
* 좌우 반쪽은 **각자의 x 축척**을 씁니다 (`W_p`, `W_n` 이 달라도 양쪽이 항상 보이게).
  슬라이드 그림도 같은 방식입니다.
* J–V 의 y축은 **현재 동작점에 맞춰 자동 확대**됩니다. 고정 축으로 두면 순방향
  무릎이 화면 끝으로 밀리고 역방향은 0 과 구분되지 않습니다.

## 5. 자체 검증

`?test=1` 또는 콘솔에서 `runSelfTests()`. 전부 통과합니다.

1. `V_a = 0` → 과잉 캐리어와 전류가 정확히 0
2. 역방향 → `J = −J_s` (그림 2)
3. Long base → 지수 감쇠, `J_n = eD_n n_p0(e^{eVa/kT}−1)/L_n`, `λ = L_n` (그림 5, 9)
4. Short base → 직선, `J_n = eD_n n_p0(e^{eVa/kT}−1)/W_p`, `λ = W_p` (그림 4, 9)
5. `J_n(x) + J_p(x) = J_Total` 이 위치에 무관하게 성립 (그림 3)
6. `J = J_s(e^{eVa/kT} − 1)` 을 정확히 따름 (그림 2)

슬라이더 전 범위 2592개 조합을 렌더링까지 돌려 오류·비유한값 0건을 확인했습니다.
