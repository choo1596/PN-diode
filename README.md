## 1. 이 시뮬레이터로 확인할 수 있는 것

| 학습 목표 | 확인 방법 |
|---|---|
| 도핑이 주입량과 포화전류를 어떻게 바꾸는가 | `Na`/`Nd` 를 움직이며 프로파일의 소수캐리어 준위, 읽기 패널의 `J0`, J–V 플롯의 `Jn`/`Jp` 분해를 관찰 |
| base 길이가 확산거리보다 길/짧아지면 분포가 어떻게 변하는가 | `Long base` / `Short base` 프리셋 → 프로파일 **과잉 캐리어만 (linear)** 모드에서 지수 감쇠 ↔ 직선 |
| 순방향 바이어스에서 저준위 주입 가정이 언제 깨지는가 | `고준위 주입 관찰` 프리셋 → `Va` 를 올리며 주입비 `r`, 선 스타일 변화, semi-log 기울기가 n=1 → n=2 로 눕는 것 관찰 |

## 2. 조작

모든 조작은 **마우스만으로** 가능합니다 (PPT 슬라이드쇼에서는 키보드 포커스가 잡히지
않기 때문입니다). 슬라이더 핸들은 24 px, 좌우 `−`/`+` 버튼으로 한 단계씩도 움직일 수
있고, **J–V 플롯 위를 클릭하거나 드래그하면 `Va` 가 그 전압으로 이동**합니다.

| 컨트롤 | 범위 | 비고 |
|---|---|---|
| `Na`, `Nd` | 1e14 – 1e19 cm⁻³ (log) | 1e19 이상이면 축퇴 경고 |
| `Va` | −2.0 – +1.0 V (5 mV 간격) | |
| `Wp`, `Wn` | 0.1 – 500 µm (log) | 준중성 영역 폭 |
| `T` | 250 – 400 K | ni, µ, Vt 에 모두 반영 |
| `Rs` | 켬/끔 (기본 켬) | `Vj = Va − J·RsA` 자기일관 해 |
| 역방향 SCR 생성전류 | 켬/끔 (기본 끔) | |

**프리셋 4종** — `강의 예제`(슬라이드 값 재현: τ 오버라이드 10 ns / 300 ns), `Long base`,
`Short base`, `고준위 주입 관찰`.

**고급 오버라이드** (기본 접힘) — `τn, τp`, `Dn, Dp`, `Ln, Lp` 를 손으로 고정해서
도핑–이동도–수명 결합을 끊고 개별 파라미터의 영향만 볼 수 있습니다. 항목마다
`자동값` 버튼으로 모델값으로 되돌립니다.

## 3. 물리 모델

내부 단위는 cm 계열(cm⁻³, cm²/s, cm, s)로 통일하고 표시할 때만 µm/ns 로 바꿉니다.

**진성 캐리어** `ni(T) = A (T/300)^2.54 exp(−6726/T)`, `A` 는 `ni(300 K) = 1.5e10 cm⁻³`
가 정확히 나오도록 정규화 (강의 손계산과 맞추기 위함, 모델 원값은 ~1.0e10).

**이동도** Caughey–Thomas (Si, 300 K)

```
mu_n(N) = 65   + (1330 − 65)  / (1 + (N / 8.5e16)^0.72)
mu_p(N) = 47.7 + (495 − 47.7) / (1 + (N / 6.3e16)^0.76)
```

온도 확장 `mu ∝ (T/300)^−2.42` (전자), `^−2.20` (정공).

**수명** — 다이얼이 아니라 도핑에서 자동으로 따라 나옵니다. Scharfetter SRH 를 Auger 와
병렬로 합칩니다.

```
1/tau_n = (1 + Na/1e16)/1.0e-5 + 9.9e-32 · Na²
1/tau_p = (1 + Nd/1e16)/3.0e-6 + 2.8e-31 · Nd²
```

**확산** `Dn = Vt·mu_n(Na)`, `Dp = Vt·mu_p(Nd)`, `L = sqrt(D·tau)`.

**공핍층** `Vbi = Vt ln(Na Nd/ni²)`, `W = sqrt(2 ε (Vbi−Vj)/q · (1/Na + 1/Nd))`,
`xn = W Na/(Na+Nd)`, `xp = W Nd/(Na+Nd)`.

### SCR 경계 조건 — 근사 없음

저준위 주입 근사 `pn(0) = pn0 exp(Va/Vt)` 를 **쓰지 않습니다.** 주입 수준과 무관하게
성립하는 두 관계를 그대로 연립해서 풉니다.

```
p·n = ni² exp(Vj/Vt)      (접합 법칙)
n − p = Nd                 (준중성)
→  pn(0) = 2 ni² exp(Vj/Vt) / ( Nd + sqrt(Nd² + 4 ni² exp(Vj/Vt)) )
```

분모를 유리화한 형태를 쓰는 이유는 역방향·저바이어스에서 `−Nd + sqrt(Nd² + ε)` 가
심각한 자릿수 손실을 일으키기 때문입니다. 지수는 로그 공간에서 다루고 안전하게
클램프합니다. 이 한 식이 분기 없이 두 극한을 모두 재현합니다.

* 저준위 주입: `dpn(0) → (ni²/Nd) exp(Vj/Vt)`, ideality **n = 1**
* 고준위 주입: `dpn(0) → ni exp(Vj/2Vt)`, ideality **n = 2**

### 분포 — long/short base 통합 일반해

준중성 영역 끝(오믹 접촉)에서 `δ = 0` 을 걸면 분기 없이 하나의 식이 됩니다.

```
dpn(x') = dpn(0) · sinh((Wn − x')/Lp) / sinh(Wn/Lp)
```

`Wn/Lp ≫ 1` 이면 `exp(−x'/Lp)` (지수 감쇠), `Wn/Lp ≪ 1` 이면 `1 − x'/Wn` (직선).
구현은 모든 지수 인자가 0 이하가 되도록 정리해서 W/L 이 아무리 커도 오버플로우가
없고, `W/L < 0.01` 에서만 선형식으로 넘어갑니다.

### 양극성 확산계수 · 전류

```
D_eff = (n + p) Dn Dp / (n Dn + p Dp)        n측에는 n = nn(0), p = pn(0)
Jp = q D_eff,p dpn(0)/Lp · coth(Wn/Lp)
Jn = q D_eff,n dnp(0)/Ln · coth(Wp/Ln)
```

저준입에서는 `D_eff → Dp`, 고준입(n ≈ p)에서는 `→ 2 Dn Dp/(Dn+Dp)` 로 자동으로 옮겨
갑니다. `J0` 는 coth 기하 인자를 포함하므로 long base 에서
`q ni² [Dp/(Lp Nd) + Dn/(Ln Na)]`, short base 에서 `q ni² [Dp/(Nd Wn) + Dn/(Na Wp)]`
로 그대로 환원됩니다.

### 직렬저항

```
Rs·A = Wn/(q mu_n(Nd) Nd) + Wp/(q mu_p(Na) Na)     [Ω·cm²]
```

준중성 영역의 **다수캐리어** 이동도를 쓴다는 점에 주의하세요(소수캐리어 D 계산과
인자 조합이 다릅니다). `Vj = Va − J(Vj)·RsA` 는 Newton 법으로 풀되 이분법
안전장치를 겹쳐 두었고(rtsafe), 슬라이더 전 범위에서 14회 이내에 수렴합니다.

### 역방향 SCR 생성전류 (선택)

`Jgen = q ni W(Vj) / (2 tau_g)`, `tau_g = sqrt(tau_n tau_p)`, 역방향에서 `J −= Jgen`.
켜면 역방향 전류가 `W ∝ sqrt(Vbi − Va)` 를 따라 완만히 증가합니다.
구현에서는 `Vj = 0` 에서 J 가 계단처럼 튀지 않도록 SRH 생성항의 원래 형태
`(1 − exp(Vj/2Vt))` 를 곱해 두었습니다 (깊은 역방향에서는 1 이므로 위 식과 같습니다).

## 4. 각 근사의 유효 범위

읽기 패널의 **주입비** `r = max( δpn(0)/n_n0 , δnp(0)/p_p0 )` 로 판정하고, 플롯에도
그대로 반영됩니다.

| 구간 | 조건 | 표시 |
|---|---|---|
| 저준위 주입 | `r < 0.1` | 실선 |
| 전이 | `0.1 ≤ r < 1` | 파선 |
| 고준위 주입 | `r ≥ 1` | 점선 + 배경 음영 + 배지 |

**꼭 알아둘 한계** — 8절의 경계조건은 주입 수준과 무관하게 정확하지만, 분포 형상
(sinh 해)과 확산거리 `L` 은 저준위 주입 가정에서 유도된 것입니다. 고준입 구간에서는
경계값 `δ(0)` 만 정확히 보정되고 **형상은 근사로 남습니다.** 고준입에서 `L` 까지
자기일관으로 푸는 것은 강의용 범위를 넘습니다. 시뮬레이터는 이 구간에서 배너와
플롯 배지로 이를 명시합니다.

그 밖의 경고:

* **공핍 근사 붕괴** — `Vj ≥ Vbi − 3Vt`. 공핍층 폭과 경계조건을 신뢰할 수 없습니다.
* **축퇴** — `Na` 또는 `Nd` ≥ 1e19 cm⁻³. 볼츠만 근사·완전 이온화 가정이 무너지고
  밴드갭 축소도 무시할 수 없습니다.
* 양극성 `D_eff` 는 사양대로 두 영역 모두 같은 `Dn`, `Dp` 를 씁니다. 엄밀하게는
  각 영역의 다수캐리어 이동도를 써야 하지만, 저준입 극한값이 정확히 재현되고
  오버라이드 동작이 예측 가능해지는 쪽을 택했습니다.
* 표시되는 `np0`, `pn0` 는 `ni²/N` 이 아니라 같은 정확해를 `Vj = 0` 에서 평가한
  값입니다. 두 값의 차이는 상대적으로 `(ni/N)² ≤ 2e-8` 이지만, 이렇게 해야
  `Va = 0` 에서 과잉 캐리어와 전류가 **정확히** 0 이 됩니다.

### 수명 모델과 강의 슬라이드 값의 차이

같은 도핑(`Na=5e17`, `Nd=2e16`)이라도

| | τn | τp | Ln | Lp | J0 |
|---|---|---|---|---|---|
| 강의 슬라이드 (측정값) | 10 ns | 300 ns | 2.97 µm | 16.8 µm | 1.22e-11 A/cm² |
| 자동 모델 (Scharfetter+Auger) | 195 ns | 1.00 µs | 13.1 µm | 30.6 µm | 6.01e-12 A/cm² |

로 다릅니다. **오류가 아닙니다.** 슬라이드의 수명은 특정 시료의 측정값이고 자동
모델은 일반적인 도핑 의존 관계입니다. 슬라이드 숫자를 재현하려면 `강의 예제`
프리셋(= τ 오버라이드 ON)을 쓰세요. 읽기 패널의 τ 항목 ⓘ 에도 같은 설명이 있습니다.

## 5. 자체 검증

헤더의 `자체 검증` 버튼 또는 `?test=1`, 콘솔에서 `runSelfTests()` 로 12개 항목을
실행합니다. 전부 통과합니다.

1. `Va = 0` → 모든 과잉 캐리어와 J 가 0 (1e-30 이내, Rs 켬/끔 모두)
2. `Va = −0.5 V` → `δpn(0) = −pn0`, `J = −J0` (상대오차 4e-9)
3. `Va = −1 V`, `Nd = 1e19` → 자릿수 손실 없이 `pn0·exp(Va/Vt)` 와 상대오차 1e-16
4. `Wn/Lp = 30` → 프로파일이 `exp(−x'/Lp)` 와 일치 (편차/δ(0) = 9e-14)
5. `Wn/Lp = 0.016` → 직선과 일치(1.7e-5), `Jp → q ni² Dp/(Nd Wn)` (9e-5)
6. `Va = 0.3 V`, `Nd = 1e17` → 정확해와 저준입 근사식이 상대오차 2.5e-9
7. 고준입(`Nd=1e15`)에서 기울기가 n=2 (8.40 dec/V) 쪽으로 누움
8. 같은 소자 저준입 구간 기울기 = n=1 (16.79 dec/V)
9. `강의 예제` 프리셋 → `Dn=8.82`, `Dp=9.39`, `Ln=2.97 µm`, `Lp=16.8 µm`, `J0=1.22e-11`
10. 자동 τ 모델 → `τn=195 ns`, `τp=1.00 µs`, `Ln=13.1 µm`, `Lp=30.6 µm`, `J0=6.01e-12`
11. `Na` ×10 → `Jn` 이 1/10 로 감소 (D·τ·L 고정 시 정확히 10.000)
12. 자기일관 Vj 해가 전 슬라이더 범위(2916 조합)에서 14회 이내 수렴

7번은 총 전류 기울기가 8.4 까지 내려가지는 않습니다. 고준입에 들어간 것은 약하게
도핑된 n 측(`Jp`, 8.56 dec/V)뿐이고, 무겁게 도핑된 p 측(`Jn`)은 여전히 저준입이라
n=1 기울기를 유지하기 때문입니다. 이것이 물리적으로 옳은 거동이며, `Jn/Jp 분해`
토글을 켜면 그대로 보입니다.

11번도 자동 모델에서는 도핑을 올릴 때 µ 와 τ 가 함께 떨어지므로 감소 비율이
도핑 구간에 따라 달라집니다 (1e14→1e15 에서 9.8배, 5e17→5e18 에서 5.1배).
`1/Na` 만의 효과를 보려면 고급 오버라이드로 D·τ·L 을 고정하세요.
